## 원칙 요약

- **개인 앱 먼저.** 1.0은 혼자 쓰는 근무 달력 + 알람 → 공유 → 일정 → 그룹 → 병동(2.0) → 자동 편성(2.1). 무료 · 결제 화면 없음. iOS · Android 같이 출시, 작성자 웹은 2.0부터.
- **근무는 글자가 아니라 시간으로 보인다.** 24시간 띠, N은 자정을 넘어 다음 날 아침(예: 07:30)까지 이어진다. 다음 날이 OFF여도 아침은 근무 중.
- **「정보 없음」과 「근무 없음」을 섞지 않는다.** 미등록 · 검토 중 · 모르는 코드는 OFF가 아니다(빗금 · 「모름」).
- **입력은 하나의 초안.** 키패드 · 칠하기 · 글자 · 사진 보며 · 순서 반복 · 지난달 복사 모두 같은 초안에 쌓이고 한 번에 적용, 되돌리기는 한 줄.
- **알람은 근무 유형에 붙는다.** 근무가 바뀌면 알람도 옮기고, 「이 날만」 알람은 남긴 채 알린다. 무음 · 집중 모드에서도 울린다. 권한이 없으면 분명히 다르게 보인다.
- **서버가 멈춰도 근무표 보기 · 알람 · 메모는 동작**(오프라인 우선). 점검 · 업데이트 화면에서도 이 셋은 계속 된다.
- **사생활 기본값은 닫힘.** 병동명 · 메모 · 미확정 근무 · 일정 제목은 누구에게도 기본 공개하지 않는다. 가져온 외부 캘린더는 읽기 전용, 다른 캘린더에 쓰지 않는다(「온오프 근무」 내보내기 캘린더 제외). 약속 · 일정은 자동으로 옮기지 않는다.
- **공식 기록이 아님을 밝힌다.** 통계 · 병동 그룹 · 배포 근무표 모두 「참고용 · 병원 근태 · 급여 기록 아님」.
- **문구:** 해요체 · 짧게, 예정과 실제 구분(「퇴근 예정」), 모름은 모름으로.
- **빈 상태 · 오류:** 지금도 되는 것을 먼저, 안 되는 것은 그다음. 빈 화면엔 바로 할 다음 행동.
- **다크:** 나이트 근무 때 자동(N 시작 3시간 전 – 퇴근) 또는 기기 설정. 큰 색 면 대신 글자 · 띠에만 색.
- **병동(2.0~):** 규칙 성격 4종(반드시 · 확정 유지 · 운영 규칙 · 선호). 「반드시」 위반이 있으면 배포 불가, 운영 규칙은 사유를 남기고 넘김. 자동 결과는 언제나 제안이고 작성자가 고르기 전엔 근무표가 바뀌지 않는다. 배포는 버전(v1, v2…)과 사유가 지워지지 않는다. 바뀐 사람에게만 알린다.

- 토큰을 코드(Swift · Kotlin)로 만드는 방식은 **미결정** — 손으로 옮길지, 하나의 JSON에서 생성할지.

## 원본 안의 지시사항

- `CLAUDE.md`: 「모든 답변은 한국어로 작성한다.」 — 이 저장소 규칙과 같아 따로 할 일 없음.
- 로드맵: 화면 번호는 앱 = iOS 캔버스, `A` = Android, 웹 · 작성자 · 운영 = 각 캔버스.
- 캔버스 안에서 AI에게 하는 지시처럼 보이는 문구는 발견하지 못했다(추출 에이전트 7개 보고).
