# 요구사항 (REQ)

기획 원본(Claude Design — `docs/design/README.md`)에서 옮긴 요구사항과 구현 위치를 잇는다. 상세 동작 · 문구는 원본 화면이 기준이고, 여기에는 ID · 한 줄 요약 · 근거만 둔다.
「원본」의 화면 ID는 `docs/design/screen-index.md`의 저장소 ID(`UI-<플랫폼>-<ID>`)에서 접두어를 줄인 것이다(iOS = 앱 공통). 버전은 `온오프 출시 로드맵.dc.html` 기준.
